# 동행 리스크 · 확인 사항

## 1. 기술 리스크
| # | 리스크 | 영향 | 대응 |
|---|---|---|---|
| R1 | FusedLocation·TTS·STT·Vehicle Control SDK "준비 중" | 위치·음성 | 준비 중 SDK 에 기능적으로 의존하지 않는다. 위치 기본 체인 = NaviHelper `onCurrentLocationInfo` → Android LocationManager → GPX Fake 이며, FusedLocation 은 `isSupported()` 와 런타임 권한 승인이 모두 true 일 때만 선택적으로 앞에 붙인다(없어도 동작). 음성 = Android `TextToSpeech`. STT 없음 → 음성 명령 제외, 프리셋 버튼·폰 메시지로 대체 |
| R2 | Vehicle SDK에 속도·기어 도메인 없음 | 급제동·정차 판정 | AAOS `CarPropertyManager`(PERF_VEHICLE_SPEED, GEAR_SELECTION) 시도 → 실패 시 위치 기반 속도 계산 |
| R3 | 비상등 값 미확인 | HAZARD 이벤트 | TurnSignal/Light capability 로그 확인 → 미지원이면 기능 숨김(기획서엔 "지원 차량에서" 표기) |
| R4 | NaviHelper 콜백이 에뮬레이터 내비 상태에 따라 안 올 수 있음 | ETA·도착 | 모든 필드 nullable, ETA 없으면 남은 거리/평균속도로 추정, 도착은 목적지 반경 150m 판정으로 보조. **2026-10-27 실측(T20):** Pleos AVD(Connect_on_x86_64, user 10)의 내비 앱 `ai.umos.maps.android.navigation.app` 은 Wi-Fi 를 켜도 "내비게이션 실행이 지연되고 있습니다" 에서 멈춰 위치·경로 콜백이 오지 않는다. 오는 것은 `onCurrentRoadSpeedLimit`(1Hz, 값 0) 과 `onNavigationStatus(INITIALIZING)` 뿐 → 위치는 T21 체인의 Android LocationManager(`adb emu geo fix` 로 주입 가능, 실측 확인) 또는 Fake(GPX) 로 공급하고, 내비 콜백은 진단 화면 "내비 이벤트" 카드로 실차에서 확인한다 |
| R5 | `addWaypoint` 결과가 내비 화면에 즉시 반영 안 될 수 있음 | 경로 따라가기 | `requestRouteWithWaypoints`로 재요청 폴백, 실패 시 "내비에서 직접 추가해 주세요" 안내 |
| R11 | **주행 중(속도 > 0) AAOS 가 비-DO(distraction optimized 아님) 액티비티를 가린다** — Pleos AVD 실측(2026-10-27, Virtual Console 속도 55): 앱 화면 대신 "주행 중에는 사용할 수 없습니다" 차단 화면 | 그룹 주행 화면·음성 안내 UI 전체 | T29 에서 주행 중 써야 하는 액티비티에 `<meta-data android:name="distractionOptimized" android:value="true"/>` 를 선언하고 `CarUxRestrictionsManager` 로 입력 UI 를 스스로 제한한다(docs/05 §4). 백그라운드 수집·발행(T23 서비스)·음성(T27)은 액티비티와 무관하게 계속 돌아야 하므로 서비스로 둔다. 기어 R 은 시스템 후방 카메라가 전면에 뜬다 |
| R6 | 에뮬레이터 2대 동시 실행 성능(RAM) | 시연 | AVD RAM 3~4GB, 호스트 RAM 16GB 이상 권장. 부족하면 B는 일반 Android Automotive/태블릿 AVD + `fake` flavor |
| R7 | Virtual Console 2대 동시 포워딩 | 시연 | 포트 분리(8088/8089). 안 되면 B 상태는 Fake 스크립트 |
| R8 | EMQX JWT 설정 난이도 | 일정 | 1주차는 HTTP 인증 훅으로 단순화 |
| R9 | 현장(PT) 네트워크 불안정 | 시연 실패 | 노트북 로컬 서버 모드 + 예비 영상 |
| R10 | Pleos Maven 저장소 접근 문제 | 빌드 | 로컬 PC(Android Studio)에서는 정상. CI 불필요, 로컬 빌드만 |
| R11 | 공식 앱(블루링크·마이현대·기아 커넥트·제네시스) 내장은 OEM 협의·SDK 배포 채널이 필요한 가정 | 폰 쪽 현실성 | `companion/sdk` 는 호스트 앱 없이 AAR 로 독립 빌드·테스트, 공개 API 6개로 최소화, demo-host 로 통합 절차를 그대로 시연. 기획서에 "OEM 협의 필요" 명시 |

## 3. 10/28 설명회 질문 리스트
1. **Q1** 차량 앱이 자체 구축한 외부 서버(클라우드)와 통신해도 되나요? 심사 시 서버를 저희가 띄워 두면 되나요?
2. **Q2** 폰 쪽을 별도 앱이 아니라 블루링크·마이현대·기아 커넥트·제네시스 앱에 내장되는 모듈(SDK)로 설계하고, 시연은 공식 앱을 흉내 낸 데모 앱으로 해도 되나요? 공식 앱 계정·차량 정보 연동은 어떤 경로로 가능한가요?
3. **Q3** 개인 참가자는 APK 파일명의 "팀명"을 어떻게 쓰나요? 블라인드 규정상 실명 대신 별칭을 써도 되나요?
4. **Q4** FusedLocation·TTS가 "준비 중"인데, 1차 제출 전 오픈 예정이 있나요? 없으면 NaviHelper 위치·Android TTS 사용이 괜찮나요?
   - 결정(답변과 무관하게 적용): FusedLocation 은 런타임 선택 사항 — `isSupported()` 와 런타임 권한이 모두 true 일 때만 위치 체인 맨 앞에 붙이고, 아니면 NaviHelper → Android LocationManager → Fake 로 동작한다(CLAUDE.md 규칙 5, R1, T21).
5. **Q5** 차량 속도·기어를 AAOS 표준 Car API로 읽어도 되나요? (Vehicle SDK에 속도 도메인이 없음)
6. **Q6** 비상등(Hazard) 상태를 읽을 수 있는 API가 있나요?
7. **Q7** 2차 PT 시연은 에뮬레이터 화면으로 하면 되나요? 현장 네트워크(인터넷) 제공되나요?
8. **Q8** 오픈소스(MIT/Apache) 라이브러리 사용 시 기획서에 표기해야 하나요?
