# 동행 데이터 모델

## 1. PostgreSQL (영구 메타데이터)

ID는 접두사 + ULID (`usr_`, `veh_`, `grp_`, `inv_`, `evt_`, `prp_`). 시간은 `timestamptz`.

```sql
-- 사용자
CREATE TABLE app_user (
  user_id        TEXT PRIMARY KEY,
  provider       TEXT NOT NULL,            -- dev | pleos | kakao | google
  provider_sub   TEXT NOT NULL,
  display_name   TEXT NOT NULL,
  created_at     TIMESTAMPTZ NOT NULL DEFAULT now(),
  UNIQUE (provider, provider_sub)
);

-- 차량 (Pleos CarInfo 차량 ID를 해시해서 저장)
CREATE TABLE vehicle (
  vehicle_id         TEXT PRIMARY KEY,
  car_info_id_hash   TEXT NOT NULL UNIQUE,   -- SHA-256(CarInfo ID + 서버 salt)
  owner_id           TEXT NOT NULL REFERENCES app_user(user_id),
  nickname           TEXT NOT NULL,
  brand              TEXT,                   -- HYUNDAI | KIA | GENESIS
  model              TEXT,
  is_primary         BOOLEAN NOT NULL DEFAULT false,
  created_at         TIMESTAMPTZ NOT NULL DEFAULT now(),
  revoked_at         TIMESTAMPTZ
);

-- 페어링 (device code)
CREATE TABLE device_authorization (
  device_code    TEXT PRIMARY KEY,
  user_code      TEXT NOT NULL UNIQUE,
  car_info_id_hash TEXT NOT NULL,
  brand TEXT, model TEXT,
  status         TEXT NOT NULL,             -- PENDING | APPROVED | CONSUMED | EXPIRED
  approved_by    TEXT REFERENCES app_user(user_id),
  nickname       TEXT,
  expires_at     TIMESTAMPTZ NOT NULL,
  created_at     TIMESTAMPTZ NOT NULL DEFAULT now()
);

CREATE TABLE refresh_token (
  token_hash   TEXT PRIMARY KEY,
  subject      TEXT NOT NULL,               -- usr_ 또는 veh_
  expires_at   TIMESTAMPTZ NOT NULL,
  revoked_at   TIMESTAMPTZ
);

-- 그룹
CREATE TABLE travel_group (
  group_id          TEXT PRIMARY KEY,
  name              TEXT NOT NULL,
  leader_vehicle_id TEXT NOT NULL REFERENCES vehicle(vehicle_id),
  dest_lat DOUBLE PRECISION, dest_lon DOUBLE PRECISION, dest_name TEXT, dest_poi_id TEXT, dest_address TEXT,
  max_members       INT NOT NULL DEFAULT 10,
  status            TEXT NOT NULL,          -- ACTIVE | ENDED
  mode              TEXT NOT NULL DEFAULT 'TRIP',  -- TRIP | FAMILY (평소 모드, P2)
  created_at        TIMESTAMPTZ NOT NULL DEFAULT now(),
  ended_at          TIMESTAMPTZ
);

CREATE TABLE group_member (
  group_id    TEXT REFERENCES travel_group(group_id),
  vehicle_id  TEXT REFERENCES vehicle(vehicle_id),
  role        TEXT NOT NULL,                -- LEADER | MEMBER
  color       TEXT NOT NULL,
  joined_by   TEXT REFERENCES app_user(user_id),
  joined_at   TIMESTAMPTZ NOT NULL DEFAULT now(),
  left_at     TIMESTAMPTZ,
  PRIMARY KEY (group_id, vehicle_id)
);

CREATE TABLE group_invite (
  token_hash  TEXT PRIMARY KEY,
  group_id    TEXT NOT NULL REFERENCES travel_group(group_id),
  expires_at  TIMESTAMPTZ NOT NULL,
  max_uses    INT NOT NULL DEFAULT 9,
  used_count  INT NOT NULL DEFAULT 0
);

-- 이벤트 로그 (24시간 보관 후 배치 삭제)
CREATE TABLE group_event (
  event_id          TEXT PRIMARY KEY,
  group_id          TEXT NOT NULL,
  type              TEXT NOT NULL,
  source_vehicle_id TEXT,
  severity          TEXT NOT NULL,
  payload           JSONB NOT NULL,
  occurred_at       TIMESTAMPTZ NOT NULL,
  created_at        TIMESTAMPTZ NOT NULL DEFAULT now()
);
CREATE INDEX ON group_event (group_id, occurred_at DESC);

-- 제안 (경로 따라가기, 휴게소)
CREATE TABLE proposal (
  proposal_id  TEXT PRIMARY KEY,
  group_id     TEXT NOT NULL,
  kind         TEXT NOT NULL,                -- ROUTE_FOLLOW | REST_STOP
  payload      JSONB NOT NULL,
  status       TEXT NOT NULL,                -- OPEN | ACCEPTED | REJECTED | EXPIRED
  created_at   TIMESTAMPTZ NOT NULL DEFAULT now(),
  closes_at    TIMESTAMPTZ NOT NULL
);
CREATE TABLE proposal_vote (
  proposal_id TEXT REFERENCES proposal(proposal_id),
  vehicle_id  TEXT,
  accepted    BOOLEAN NOT NULL,
  voted_at    TIMESTAMPTZ NOT NULL DEFAULT now(),
  PRIMARY KEY (proposal_id, vehicle_id)
);
```
마이그레이션 도구: Flyway (`src/main/resources/db/migration/V1__init.sql`).

## 2. Redis (실시간 상태, 모두 TTL)

| 키 | 타입 | 값 | TTL |
|---|---|---|---|
| `veh:{vid}:state` | Hash | lat, lon, heading, speedKph, gear, fuelPct, socPct, etaDestTs, etaRemainM, ts, locSource | 10분 |
| `veh:{vid}:group` | String | groupId | 그룹 종료 시 삭제 |
| `grp:{gid}:members` | Set | vehicleId들 | 그룹 종료 시 삭제 |
| `grp:{gid}:geo` | GEO | 멤버 위치 (GEOADD) | 10분 |
| `grp:{gid}:drivingSince` | String | 연속 주행 시작 ts | 그룹 종료 시 삭제 |
| `evt:dedup:{vid}:{type}` | String | 1 | 120s |
| `devcode:poll:{deviceCode}` | String | 마지막 폴링 ts (rate limit) | 15분 |

## 3. 차량 앱 로컬 저장

- **DataStore (Preferences):** `vehicleAccessToken`(EncryptedSharedPreferences 또는 Keystore 래핑), `refreshToken`, `vehicleId`, `activeGroupId`, 공유 항목 설정
- 위치·이벤트는 로컬에 저장하지 않음 (메모리 버퍼만, 재연결 시 최근 30초 이벤트만 재전송)

## 4. 도메인 모델 (Kotlin, 차량 앱·서버 공용 스키마)

공용 모듈 `protocol`(Kotlin Multiplatform 또는 단순 JVM 라이브러리)에 `kotlinx.serialization` 데이터 클래스로 정의해서 서버·차량 앱이 같은 코드를 쓴다.

```kotlin
@Serializable data class Envelope<T>(val v: Int = 1, val type: String, val vid: String, val ts: Long, val seq: Long, val data: T)
@Serializable data class Telemetry(val lat: Double, val lon: Double, val heading: Float?, val speedKph: Float?,
    val locSource: LocSource, val gear: String? = null, val eta: Eta? = null, val energy: Energy? = null)
@Serializable data class Eta(val destTs: Long?, val remainM: Int?, val remainS: Int?)
@Serializable data class Energy(val fuelPct: Int? = null, val socPct: Int? = null)
@Serializable enum class LocSource { NAVI, FUSED, ANDROID, FAKE }
@Serializable data class GroupEvent(val eventId: String, val type: GroupEventType, val sourceVehicleId: String?,
    val severity: Severity, val speech: String?, val payload: JsonObject)
```
