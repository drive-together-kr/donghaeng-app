## 1. 앱 이름 · 한 줄 소개
**동행(DongHaeng)** — 여러 대의 현대·기아·제네시스 차가 함께 이동할 때 위치·도착 예정 시각·차량 상태·경로를 차끼리 자동으로 나누고, 운전자에게는 **음성으로만** 알려 "어디쯤이야?" 전화 없이 한 대처럼 움직이게 해 주는 Pleos 차량 앱.

## 2. 문제 정의 (창의성)
- 가족·친구가 차 2~3대로 명절 귀성·여행·캠핑·동호회 투어를 갈 때, 동승자가 전화·메신저로 "앞차 어디야", "휴게소 들르자"를 **중계**한다.
- **운전자 혼자 탄 차**는 운전 중 통화가 위험해 그룹에서 소외된다.
- 앞차가 경로를 바꾸면 뒤차는 **내비를 다시 입력**해야 하고, 한 차의 **배터리·연료 부족, 급제동, 휴게소 도착**은 누가 말해 주기 전까지 아무도 모른다.

## 3. 해결 — 핵심 기능
| 기능 | 내용 |
|---|---|
| QR 그룹 연결 | 선두차 화면의 초대 QR 을 폰 공식 앱(동행 메뉴)으로 스캔 → **함께 갈 차를 골라 적용** → 그 차 화면에 그룹이 뜬다(차는 QR 을 보여 주기만, 스캔은 폰) |
| 실시간 공유 | 차 간 앞/뒤 간격, 그룹·내 차 도착 예정 시각, 잔량 — 주행 중엔 순정 내비 위 작은 패널, 정차 중엔 대시보드 |
| 차량 상태 자동 전달 | 저잔량, **급제동(경로상 뒤에 있는 차에만)**, 에어백 — 사람이 말하지 않아도 차가 알린다 |
| 음성 안내 | 모든 소식을 TTS 로. 급제동·에어백은 빨간 강조, 음성이 늦으면 화면 먼저 |
| 선두 경로 따라가기 | 선두가 휴게소를 경유지로 넣으면 뒤차에 "따라갈까요?" → 수락 시 뒤차 **순정 내비 경로에 그대로** 들어간다(주행 중엔 "네/아니" 음성으로 답) |
| 도착·경유지 알림 | 내비 도착 이벤트로 "둘째 차가 덕평휴게소에 도착했어요" |
| 무전(핸들 버튼) | 핸들 ▶‖ 버튼 → 말하고 다시 누름 → "보낼까요?" "네" → 그룹 차에서 자동 재생 |
| 동승자 메시지 | 폰에서 보낸 메시지를 운전자는 듣기만 |

## 4. 차량 특화성 — 왜 폰이 아니라 차인가
- **주행 중 앞 화면은 늘 순정 내비.** 동행은 내비 위 작은 패널(화면 폭 22% 이하, 회전 안내·버튼을 피함)·음성·내비 경유지로만 알린다. 주행 중 화면 조작은 [무전] 한 번뿐(CarUxRestrictions), 나머지는 정차 중에만.
- **차량 데이터가 정보원**: Vehicle SDK 의 EV 배터리·브레이크·기어·속도, NaviHelper 의 위치·도착 예정·도착 이벤트·경로. 사람이 입력하지 않는다.
- **차량 버튼**: 순정 내비가 앞에 있어도 핸들 재생/정지 버튼으로 무전(그룹 주행 중 + 설정 켜짐일 때만, 음악 재생 중이면 원래 동작).
- 차량 **제어(Set) API 는 쓰지 않는다** — 조회만. 경로 변경도 운전자가 수락해야만.

## 5. 기술 활용성 — Pleos SDK 를 핵심 기능에 쓰는 곳
| SDK | 쓰는 곳 |
|---|---|
| Vehicle | EV 배터리·연료(저잔량), 브레이크·속도(급제동 판정), 기어(주행/정차), 방향지시등, 에어백 — 지원 여부를 먼저 확인하고 미지원 신호는 숨김 |
| NaviHelper | 현재 위치, 남은 거리·도착 예정, 회전 안내(TBT — 카드가 회전 안내를 가리지 않게 300 m 게이트), 목적지·경유지 변경 감지(선두 경로 공유), 도착 이벤트, 경유지 포함 경로 요청(따라가기), 내비 화면 열기 |
| FusedLocation | 승인되면 위치 체인 맨 앞(없으면 NaviHelper → Android 위치로 자동 전환) |
| TextToSpeech · SpeechToText | 음성 안내의 대체 경로(Android TTS 가 없을 때 Pleos TTS ON_DEVICE), 무전 "보낼까요?"에 대한 "네/아니" 인식 1순위 |
| (Android) CarUxRestrictions · MediaSession | 주행 중 입력 제한, 핸들 미디어 버튼 |
- 서버: Kotlin·Spring Boot + EMQX(MQTT) + Redis + PostgreSQL, 클라우드(AWS) TLS 8883 + 막힌 망은 WSS 자동 전환. 폰 쪽은 공식 앱에 넣을 수 있는 companion SDK(공개 API 6개) + 시연용 호스트 앱.

## 7. 사업성
- **타깃**: 가족 여행·명절 귀성(2~3대), 친구 그룹 여행, 동호회 투어(5~10대), B2B(단체 렌터카·의전·이사 차량 동행).
- **수익**: B2C 기본 무료(2대·이벤트) + 프리미엄 구독(최대 10대·이동 기록·가족 상시 모드), B2B 대열 관리 콘솔 라이선스, 그룹 휴게소 제안 시 제휴 매장 쿠폰(다인원 동시 방문).
- **지속 이용**: 여행이 아닐 때도 가족 상시 그룹("엄마 차 도착 10분 전", "아빠 차 배터리 10%").
- **현대차그룹 관점**: 현대·기아·제네시스끼리 연결되는 경험 → 가족·지인 동반 구매, 공식 앱(블루링크·마이현대·기아 커넥트·제네시스)에 동행 메뉴 내장.

## 8. 안전 · 개인정보
- 정보 공유 앱이며 충돌 방지 장치가 아니다 — 지연·끊김에도 위험해지지 않게 설계(늦게 도착한 급제동은 알리지 않음, 오래된 안내 생략).
- 위치는 **그룹 안에서만, 이동하는 동안만**. 그룹이 끝나면 위치·이벤트·무전 삭제, 로그에 좌표·닉네임·토큰 원문을 남기지 않는다.
