# 동행 차량 앱 설계 (Pleos Connect / AAOS)

## 1. 기술 스택

| 항목 | 선택 | 비고 |
|---|---|---|
| 언어 | Kotlin 2.0.x | |
| UI | Jetpack Compose + Material3 | Pleos 디자인 가이드 참고 |

### 1.2 매니페스트 권한 (최소 권한 원칙)
```xml
<uses-permission android:name="android.permission.INTERNET" />
<uses-permission android:name="android.permission.ACCESS_NETWORK_STATE" />
<!-- 위치 폴백: Android LocationManager (§3.2 3순위, T21). API 31+ 에서는 FINE 요청 시 COARSE 도 함께 선언 -->
<uses-permission android:name="android.permission.ACCESS_FINE_LOCATION" />
<uses-permission android:name="android.permission.ACCESS_COARSE_LOCATION" />
<!-- 그룹 활성 중 포그라운드 서비스 DriveSessionService (§6, T23). targetSdk 34+: foregroundServiceType="location" 에 FOREGROUND_SERVICE_LOCATION 필요, API 33+: 알림 표시에 POST_NOTIFICATIONS -->
<uses-permission android:name="android.permission.FOREGROUND_SERVICE" />
<uses-permission android:name="android.permission.FOREGROUND_SERVICE_LOCATION" />
<uses-permission android:name="android.permission.POST_NOTIFICATIONS" />
<!-- 이하 Pleos 차량 권한은 pleos flavor 매니페스트(src/pleos/AndroidManifest.xml)에만 선언 -->
<!-- Vehicle SDK (조회만) -->
<uses-permission android:name="pleos.car.permission.CAR_INFO" />     <!-- CarInfo: 차량 ID -->
<uses-permission android:name="pleos.car.permission.CAR_DRIVE" />    <!-- Brake, DrivingMode, Odometer -->
<uses-permission android:name="pleos.car.permission.CAR_ENERGY" />   <!-- Fuel, EvBattery -->
<uses-permission android:name="pleos.car.permission.CAR_LIGHTS" />   <!-- Light, TurnSignal -->
<uses-permission android:name="pleos.car.permission.CAR_SAFETY" />   <!-- Safety: 에어백 -->
<!-- NaviHelper -->
<uses-permission android:name="pleos.car.permission.NAVI_ROUTE" />
<uses-permission android:name="pleos.car.permission.NAVI_ROUTE_SEARCH" />
<!-- FusedLocation (오픈 시) — 런타임 권한. isSupported() 와 승인이 모두 true 일 때만 선택적으로 사용(CLAUDE.md 규칙 5) -->
<uses-permission android:name="pleos.car.permission.FUSED_LOCATION" />
<!-- 속도·기어: AAOS 표준 Car API 시도용. CAR_SPEED 는 런타임 권한(아래) -->
<uses-permission android:name="android.car.permission.CAR_SPEED" />
<uses-permission android:name="android.car.permission.CAR_POWERTRAIN" />
```
`pleos.car.permission.*` 와 `android.car.permission.CAR_POWERTRAIN` 은 normal(설치 시 자동 승인, 런타임 팝업 없음 — 공식 샘플 가이드).
`android.car.permission.CAR_SPEED` 는 dangerous(런타임, 그룹 '차량 정보')로 Pleos AVD 에서 `granted=false` 로 설치된다(dumpsys 실측).
ACCESS_FINE_LOCATION·POST_NOTIFICATIONS·(FusedLocation 사용 시) FUSED_LOCATION 과 함께 **정차 상태(isRequiresDistractionOptimization=false)에서 1회** 요청하고
(그룹 세션 시작 시점, T22/T23), 거부 시 속도는 Haversine 계산으로 폴백한다(`VehicleCapabilities.speed=false`, §3.2). 위치·알림 권한은 그룹 세션이 시작되기 전에는 요청하지 않는다.

## 3. 어댑터 인터페이스

```kotlin
interface VehicleAdapter {
    suspend fun vehicleId(): String?                    // CarInfo 차량 ID
    fun fuelPercent(): Flow<Int?>                       // Fuel.registerFuelPercent
    fun evStateOfCharge(): Flow<Int?>                   // EvBattery.registerEvBatteryStateOfCharge
    fun brakePedal(): Flow<Boolean>                     // Brake.registerBrakePedalStatus
    fun turnSignal(): Flow<TurnSignalState>             // TurnSignal.registerTurnSignalState
    fun airbagDeployed(): Flow<Boolean>                 // Safety.registerSeatAirbagDeployed
    fun speedKph(): Flow<Float?>                        // AAOS CarPropertyManager PERF_VEHICLE_SPEED (실패 시 empty)
    fun gear(): Flow<Gear?>                             // AAOS GEAR_SELECTION (실패 시 empty)
    suspend fun capabilities(): VehicleCapabilities     // 각 check*Capabilities 결과 요약
}

interface NaviAdapter {
    fun events(): Flow<NaviEvent>   // CurrentLocation, TripInfo, DrivingInfo, RouteStateInfo,
                                    // DestinationChanged, WaypointChanged, WaypointArrived, DestinationArrived,
                                    // SpeedLimit, NavigationStatus, Error
    suspend fun requestRoute(dest: Place)
    suspend fun requestRouteWithWaypoints(dest: Place, waypoints: List<Place>)
    suspend fun addWaypoint(place: Place, index: WaypointIndex = WaypointIndex.FIRST)
    suspend fun currentDestination(): Place?
    suspend fun showNavigation()
}

interface LocationAdapter { fun locations(): Flow<Fix> }   // Fix(lat, lon, heading, accuracy, ts, source)
interface VoiceAdapter { suspend fun speak(text: String, priority: Priority); fun stop() }
```

### 3.1 Pleos SDK 사용 규칙 (공식 문서·샘플 기준)
- `Vehicle(context).initialize()` 후 `vehicle.getFuel()` 등 `getXxx()`로 도메인 객체를 얻는다. 사용이 끝나면 `vehicle.release()`.
- get·set·capability 결과는 `onComplete`/`onFailed` 비동기 람다. **콜백이 끝나기 전에 release 금지.**
- 구독은 `registerXxx(listener)` / `unregisterXxx(listener)` — **등록한 같은 리스너 객체·같은 area로 해제.**
- 지원 여부를 먼저 `checkXxxCapabilities`로 확인하고, 미지원이면 그 기능을 UI에서 숨긴다.
- NaviHelper: `NaviHelper(context)` → `initialize()` → `addListener(NaviHelperEventListener)` → 요청 → `removeListener` → `release()`.
  - 경로 요청 데이터: `RouteInfo(latitude, longitude, poiId, poiName, poiSubId, address)`,
    `RequestWaypointInfo(..., waypointIndex = WaypointIndex.FIRST, ...)`, `RouteWithWaypointsRequest(destination, waypoints)`
  - 사용하는 콜백: `onCurrentLocationInfo`, `onTripInfo`, `onDrivingInfo`, `onRouteStateInfo`, `onDestinationChanged`,
    `onWaypointChanged`, `onWayPointArrived`, `onDestinationArrived`, `onRouteStarted`, `onRouteEnded`, `onRouteCancelled`,
    `onCurrentRoadSpeedLimit`, `onNavigationStatus`, `onError`
  - 실제 전달되는 이벤트는 Navigation 앱 상태에 따라 다를 수 있으므로 **모든 필드를 nullable로 다룬다.**
- 데이터 클래스 필드명은 SDK 버전에 따라 다를 수 있다 → 어댑터 안에서만 SDK 타입을 다루고, 밖으로는 우리 도메인 타입으로 변환.

### 3.2 위치 소스 우선순위
1. `FusedLocation.isSupported()` 와 `pleos.car.permission.FUSED_LOCATION` 런타임 승인이 **모두** true → FusedLocation (선택 사항 — Playground 상 "준비 중"이지만 SDK는 배포됨, 에뮬레이터에서 런타임 확인. 없어도 아래 체인으로 동작, CLAUDE.md 규칙 5)
2. NaviHelper `onCurrentLocationInfo` (주력 대안)
3. Android `LocationManager` (AAOS 표준)
4. Fake (GPX 재생, 개발·데모용)

속도: Car API → 실패 시 연속 위치로 계산(Haversine / Δt, 3샘플 이동평균).

### 3.3 급제동 판정 (EventDetector)
- 조건: 브레이크 ON && (1초 내 속도 감소 ≥ 14.4 km/h ≈ 4 m/s²) && 직전 속도 ≥ 40 km/h
- 쿨다운 30초. 서버도 120초 중복 억제.
- 비상등: TurnSignal 상태가 좌·우 동시 표시를 지원하면 `HAZARD_ON`, 아니면 기능 숨김 (capability 결과 로그로 확인).

## 4. 주행 중 UX 제한
- `CarUxRestrictionsManager`로 `isRequiresDistractionOptimization` 구독 → 주행 중 입력 버튼·스크롤·QR 화면 비활성.
- 주행 중 허용: 그룹 지도·리스트 보기, 음성 안내, 음성 "응/아니" 대신 **스티어링 버튼 없이 자동 기본값**(제안은 30초 후 자동 거절, 정차 시 다시 노출).
- 오디오 포커스: 음성 안내 시 `AUDIOFOCUS_GAIN_TRANSIENT_MAY_DUCK`, TTS 앞에 선행 묵음(Pleos 가이드) 200ms.

## 6. 백그라운드 동작
- 그룹 활성 중에는 **포그라운드 서비스**(`DriveSessionService`)가 텔레메트리·MQTT·음성을 담당 → 다른 앱이 화면을 차지해도 동작.
- 그룹 비활성 시 서비스 종료(불필요한 상주 금지, Pleos 리소스 가이드).
- 앱 프로세스 재생성 시 `activeGroupId`로 자동 재연결.
- **(T16 구현 메모)** MQTT 접속은 그룹 전에도 유지한다: 폰(companion)이 이 차를 그룹에 넣는 순간 서버가 `dh/v1/vehicle/{vid}/cmd` 로 `GROUP_JOINED` 를 보내므로(docs/03 §5.5, T18) 차량은 페어링만 돼 있으면 cmd 를 듣고 있어야 한다. `MqttSessionManager` 가 Application 에서 시작해 페어링 상태(TokenStore)를 보고 붙고 끊으며, `GROUP_JOINED` 를 받으면 `GroupSessionStore`(DataStore `group_session`)에 저장하고 그룹 `state/event` 를 구독한다. 포그라운드 서비스(T23)는 이 연결을 백그라운드에서 유지하는 역할만 더한다.

## 7. 설정·빌드 변형
```
buildTypes: debug / release
productFlavors(adapter): pleos (실 SDK) / fake (전부 Fake — 일반 폰·태블릿 에뮬레이터에서도 실행)
BuildConfig.DH_PUBLIC_BASE_URL : local = http://10.0.2.2:8080  /  cloud = https://<VM-IP>.sslip.io   (서버 DH_PUBLIC_BASE_URL 과 동일. Gradle 속성 dhPublicBaseUrl, -PdhPublicBaseUrl=… 로 덮어쓰기)
BuildConfig.DH_MQTT_PUBLIC_URI : local = tcp://10.0.2.2:1883   /  cloud = ssl://<VM-IP>.sslip.io:8883   (서버 DH_MQTT_PUBLIC_URI 와 동일. Gradle 속성 dhMqttPublicUri)
코드 접근자: core/network/ServerConfig.publicBaseUrl / .mqttPublicUri (BuildConfig 를 밖에서 직접 읽지 않는다)
※ 매니페스트 usesCleartextTraffic 은 dhPublicBaseUrl 이 http:// 일 때만 true(placeholder). HiveMQ(tcp://)에는 적용되지 않으므로
   MqttGateway(T16)는 DH_PUBLIC_BASE_URL 이 https 일 때 ssl:// 만 허용한다.
※ 차량 앱은 QR 문자열을 직접 만들지 않는다. 페어링 QR(verifyUri)·그룹 QR(invite.url)은 서버 응답을 그대로 표시한다(도메인 비의존).
```
APK 파일명 규칙(공모전): `팀명_앱이름_release.apk` → `{팀명}_동행_release.apk` (GitHub `apk/` 폴더). 개인 참가 시 "팀명" 자리에 무엇을 쓰는지는 설명회 Q3 답변으로 확정하되, 블라인드 심사이므로 저장소·README·APK 메타데이터에 실명·학교를 쓰지 않는다.
