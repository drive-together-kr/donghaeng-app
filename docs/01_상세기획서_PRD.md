## 1. 한 줄 소개

**차 여러 대가 함께 이동할 때, 각 차의 위치·도착 시간·차량 상태·경로를 차끼리 자동으로 공유해서 "어디쯤이야?" 전화 없이 한 대처럼 움직이게 해 주는 Pleos 차량 앱.**

## 2. 문제 정의

### 2.1 불편한 순간
- 가족·친구가 차 2~3대로 명절 귀성, 여행, 캠핑, 동호회 투어를 갑니다.
- 이동 내내 동승자가 **통역사 역할**을 합니다. "앞차 어디야?", "휴게소 들르자", "우리 먼저 간다"를 전화와 카톡으로 중계합니다.
- **운전자 혼자 탄 차**는 운전 중 통화가 위험해서 그룹에서 소외됩니다.
- 앞차가 경로를 바꾸면 뒤차 운전자가 **내비를 직접 다시 입력**해야 합니다.
- 한 차의 **연료·배터리가 부족**하거나 **휴게소에 들어갔는지**는 상대가 말해 주기 전까지 아무도 모릅니다.

### 2.2 왜 폰으로는 안 되는가 (차량특화성의 근거)
| 상황 | 폰(전화·위치공유 앱) | 동행 |
|---|---|---|
| 운전자 혼자인 차 | 운전 중 조작 불가 | 자동 공유 + 음성 안내 |
| 차량 상태(연료·배터리·급제동·에어백) | 사람이 말해야 앎 | 차량 데이터가 자동 전달 |
| 차 3대 이상 | 1:1 통화 중계 반복 | 그룹 전체 동시 전달 |
| 경로 변경 | 말로 듣고 내비 재입력 | 선두차 경유지를 뒤차 내비에 바로 세팅 |
| 휴게소·목적지 도착 | 누군가 확인하고 전화 | 내비 도착 이벤트로 자동 알림 |

### 2.3 해결 방향
차량 SDK(Vehicle·NaviHelper)가 이미 알고 있는 정보를 **그룹 안에서만, 이동하는 동안만** 공유한다. 사람은 아무것도 하지 않고, 필요한 순간에만 음성으로 듣는다.

## 3. 타깃 사용자

| 페르소나 | 상황 | 핵심 가치 |
|---|---|---|
| **P1. 가족 여행 운전자** (30~50대) | 명절 귀성, 주말 여행에 부모님 차·형제 차와 함께 이동 | 전화 없이 서로 위치·도착 시간 확인, 휴게소 함께 정차 |
| **P2. 친구·연인 그룹 여행** (20~30대) | 렌터카+자차, 2~3대로 캠핑·드라이브 | 선두차 경로 따라가기, 맛집·휴게소 경유지 공유 |
| **P3. 동호회·투어 리더** | 자동차 동호회 정기 투어, 캠핑 모임 (5~10대) | 대열 관리, 이탈 감지, 집결지 안내 |
| **P4. B2B 운영자** (확장) | 단체 렌터카 투어, 의전·행사 차량 대열, 이사 차량 동행 | 대열 운영 효율, 기록 |

**평소 모드(Retention 확보용):** 여행이 아닐 때도 가족끼리 "엄마 차 도착 10분 전", "아빠 차 연료 10%" 같은 가족 차량 상태를 공유합니다(P1 확장).

## 4. 핵심 기능 (우선순위)

P0 = 1차 접수 데모 필수, P1 = 2차 PT 전까지, P2 = 기획서 확장 계획

| ID | 기능 | 설명 | 우선순위 |
|---|---|---|---|
| F1 | **QR 그룹 연결** | 방장 차 화면에 QR → 따라가는 차의 운전자/동승자가 폰 앱으로 스캔 → 그 사람 계정에 연결된 차가 그룹에 합류 | P0 |
| F2 | **차량 페어링** | 최초 1회 차 화면 QR(기기 인증 코드)을 폰 앱으로 스캔해 "내 차"로 등록 (OAuth Device Authorization Grant 방식) | P0 |
| F3 | **실시간 위치·ETA 공유** | 그룹원 차 위치를 지도에 표시, 각 차의 목적지 도착 예정 시간·남은 거리 표시 | P0 |
| F4 | **차량 상태 공유** | 연료/배터리 잔량, 저잔량 경고, 급제동, 에어백 전개를 그룹에 자동 전달 | P0 |
| F5 | **이벤트 음성 안내** | "앞차가 OO휴게소에 들어갔어요", "△△님 차 연료 12%" 같은 이벤트를 음성(TTS)으로 안내 | P0 |
| F6 | **선두차 경로 동기화** | 선두차가 목적지·경유지를 바꾸면 뒤차에 "경로를 따라갈까요?" → 수락 시 NaviHelper로 경유지 세팅 | P0 |
| F7 | **도착·경유지 자동 알림** | NaviHelper 도착 이벤트로 "휴게소 도착", "목적지 도착"을 그룹에 공유 | P0 |
| F8 | **원탭 프리셋 메시지** | 정차 중 "휴게소 들르자 / 먼저 가 / 잠깐 멈춰" 버튼, 주행 중에는 음성으로만 수신 | P1 |
| F9 | **그룹 휴게소 자동 제안** | 그룹 중 한 대라도 연료·배터리 부족, 또는 연속 주행 2시간 초과 → 경로상 다음 휴게소를 모두에게 제안 | P1 |
| F10 | **대열 이탈 감지** | 선두차와 경로·거리가 크게 벌어지면 이탈 알림 | P1 |
| F11 | **동승자 폰 메시지** | 동승자가 폰 앱에서 텍스트 입력 → 그룹 차량에서 TTS로 읽힘 | P1 |
| F12 | **지연·끊김 처리** | 메시지 타임스탬프로 오래된 이벤트 음성 생략, 터널 등 끊김 시 마지막 속도·방향으로 위치 추정 | P1 |
| F13 | **가족 평소 모드** | 상시 그룹(가족)을 만들어 출발·도착·저잔량만 공유 | P2 |
| F14 | **이동 기록 리포트** | 여행 종료 후 함께 달린 경로·정차 기록 요약 (공유 카드) | P2 |
| F15 | **B2B 대열 관리 콘솔** | 운영자 웹 콘솔에서 다수 차량 대열 모니터링 | P2 |

### 4.1 안전 원칙 (기획서에 명시)
- 동행은 **정보 공유 앱**이며 충돌 방지·안전 보조 장치가 아닙니다. 지연·끊김이 생겨도 위험해지지 않도록 설계합니다.
- 주행 중에는 **화면 조작 없음** — 지도·상태 확인과 음성 안내만. 입력은 정차(P단) 중에만 허용 (CarUxRestrictions 준수).
- 차량 **제어 기능은 쓰지 않습니다.** 경로 변경도 운전자가 "수락"해야만 세팅됩니다.

## 5. 사용자 흐름

### 5.1 최초 1회 — 차량 페어링 (F2)
1. 차에서 동행 앱 실행 → "내 폰과 연결하기" → 화면에 페어링 QR + 6자리 코드
2. 폰 앱 로그인(카카오/구글/추후 Pleos ID) → "차 등록" → QR 스캔
3. 서버가 `vehicleId`(CarInfo 차량 ID) ↔ `userId` 연결 → 차 화면에 "○○님 차량으로 등록됐어요"

### 5.2 그룹 만들기·합류 (F1)
1. 방장 차(정차 중) → "같이 가기 시작" → 목적지 선택(현재 내비 목적지 자동 불러오기) → 그룹 QR 표시
2. 따라가는 차의 운전자/동승자가 폰 앱으로 QR 스캔 → "추석 귀성길 그룹에 참여"
3. 서버가 스캔한 사용자의 등록 차량을 그룹에 추가 → 해당 차량에 MQTT로 합류 명령 → 차 화면 "그룹 연결됨" + 선두차 목적지로 경로 설정 제안
4. 미리 정한 여행이면 카톡 초대 링크로 같은 처리(전날 합류, 당일 시동만 걸면 자동 연결)

### 5.3 이동 중
- 지도: 그룹원 차 아이콘(색·이름), 각 차 ETA, 선두와의 거리
- 이벤트 → 음성: 휴게소 진입, 저잔량, 급제동(시야 밖 상황 공유), 경로 변경 제안, 프리셋 메시지
- 휴게소 제안: "△△님 차 연료 12%. 18km 앞 OO휴게소에서 다 같이 쉬어갈까요?" → 각 차 "응/아니"(음성 or 정차 시 버튼)

### 5.4 종료
- 목적지 도착 시 자동 종료 제안, 또는 방장 종료 → 위치 데이터 즉시 삭제, 요약 기록만 보관(동의 시)

## 6. 화면 구성 (차량 앱)

| 화면 | 주요 요소 | 주행 중 |
|---|---|---|
| S1 홈 | 그룹 시작 / 참여 중 그룹 / 내 차 연결 상태 | 표시만 |
| S2 페어링 | 페어링 QR, 6자리 코드, 남은 시간 | 비활성 |
| S3 그룹 생성 | 그룹 이름, 목적지(내비 연동), 그룹 QR | 비활성 |
| S4 그룹 주행 (메인) | 좌: 그룹원 리스트(이름·ETA·잔량·상태 배지) / 우: 지도 | 표시만 |
| S5 이벤트 피드 | 시간순 이벤트, 지연 표시("5초 전") | 표시만 |
| S6 프리셋 메시지 | 큰 버튼 4~6개 | 비활성 |
| S7 설정 | 공유 항목 on/off, 음성 안내 범위, 그룹 나가기 | 비활성 |

Pleos 멀티윈도우 대응: portrait(1창) = 그룹원 리스트 중심, landscape(2창) = 리스트 + 지도.

## 9. 경쟁·대체재

| 대체재 | 한계 |

| 전화·카톡·위치공유(카카오맵 친구 위치 등) | 폰 조작 필요, 차량 상태·내비 연동 없음, 운전자 혼자 탄 차 사용 불가 |

| OEM 순정 기능 | 현대·기아 순정에 그룹 주행 기능 없음 (기획 시점 확인 기준) |

## 10. 사업 모델

- **B2C 프리미엄 구독:** 기본(2대·이벤트 공유) 무료, 프리미엄(최대 10대·이동 기록·가족 상시 모드) 월 구독
- **B2B 대열 관리:** 단체 렌터카·투어·의전 차량 운영사 대상 콘솔 라이선스
- **휴게소·제휴 POI:** 그룹 휴게소 제안 시 제휴 매장 쿠폰(다인원 동시 방문 = 높은 객단가)
- **현대차그룹 관점:** "현대·기아끼리 연결되는 차" → 가족·지인 간 브랜드 동반 구매 유도, Pleos App Market 대표 소셜 앱

## 11. 발전 계획

1. **1단계 (공모전):** Pleos 앱 + 폰 동반 앱 + 서버, 현대·기아·제네시스 간 연결
2. **2단계:** Pleos ID·Vehicle Data API 정식 연동(별도 폰 로그인 없이 마이현대·기아 계정으로 연결), Pleos STT/TTS·FusedLocation 정식 SDK 전환
3. **3단계:** 차량 V2X 모듈 개방 시 급제동 등 안전 이벤트만 직접 통신으로 전환, 동호회·B2B 콘솔
4. **4단계:** 해외(현대차그룹 글로벌 Pleos 탑재 차량) 확장
